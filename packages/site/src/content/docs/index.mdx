## What it does

ireko (入れ子) is the Japanese word for a set of boxes that fit inside each other. A diagram is a tree of nodes. Each node selects two things for its children:

- **The strategy:** how to arrange the children. The built-in strategies are `grid` and `radial`, and you can add your own.
- **The mode:** where the children go. In the `nested` mode, the children are inside the box of the node. In the `linked` mode, they are around it, and edges connect them.

One layout gives plain data: boxes, routed edges and findings. Any renderer can draw it.

## Use it in your code

```ts
import { grid, layout, radial } from "ireko";
import { toSVG } from "ireko/svg";

const root = grid.nested("system", radial.nested("web", "home", "cart", "search"), grid("api", "auth", "orders"));

const result = layout({ root });
result.nodes; // { id, x, y, width, height, container, ... } for each box
result.issues; // the findings of the audit: an empty list
document.body.innerHTML = toSVG(result);
```

The [quick start](/learn/quick-start/) has the steps for React, React Flow and the server.
